# Driftwear Clo.

Premium Next.js website for Driftwear Clo., a Sri Lankan custom T-shirt and DTF clothing printing brand.

## Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

# Admin Guide

The admin dashboard is a secure-admin-ready mock UI. It does not persist changes yet.

Planned sections:

- Dashboard overview
- Orders
- Custom design requests
- Artwork files
- Products
- Product categories
- Inventory
- Bulk quote requests
- Customers
- Gallery
- Videos
- Testimonials
- Homepage content
- Coupons
- Delivery settings
- Contact submissions
- Website settings

Supported order statuses in the UI plan: New, Awaiting Artwork, Design in Progress, Awaiting Approval, Approved, Printing, Ready, Shipped, Completed and Cancelled.

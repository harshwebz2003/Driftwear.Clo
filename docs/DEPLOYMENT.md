# Deployment

This is a static HTML/CSS/JS website.

## Netlify

1. Deploy the project folder.
2. Set publish directory to the project root.
3. No build command is required.

## Production checks

- Test `index.html` at 320, 375, 430, 768, 1024, 1280, 1440 and 1920 px.
- Check shop filters, product quick view, customizer upload, cart, checkout, WhatsApp links and all navigation.
- Replace placeholder legal text and unverified demo content.
- Optimize real images to WebP or AVIF before upload.

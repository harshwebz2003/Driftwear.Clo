# Image Replacement Guide

Current images are local placeholders from the existing workspace.

Recommended replacement paths:

- Hero shirts: `public/images/hero/`
- Product images: `public/images/products/`
- Service visuals: `public/images/services/`
- Gallery/process images: `public/images/gallery/` and `public/images/process/`
- Model photos: `public/images/models/`
- Testimonial avatars: `public/images/testimonials/`
- Collection covers: `public/images/categories/`
- Packaging: `public/images/packaging/`
- Video posters: match the video folder and use descriptive filenames

After replacing files, update image paths in `script.js` product, gallery, service and testimonial data.
